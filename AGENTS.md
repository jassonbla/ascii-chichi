# AGENTS.md

Guidance for coding agents that work in this repository.

## What this is

A single-page demo: the character Chichi drawn as live ASCII art on a 2D canvas. Read `README.md` first for the behavior, the rendering steps, and the clip data format.

## Layout

- `index.html` holds everything: markup, styles, and one inline `<script type="module">`.
- `assets/*.bin` and `assets/clips.json` are generated by `tools/bake.py`. Do not edit them by hand.
- `tools/bake.py` is the only code outside the page. It needs `ffmpeg` and `numpy`.

There is no package manager, no bundler, no framework, and no test suite. Keep it that way unless the user asks for a change.

## Run and verify

```sh
python3 -m http.server 8000
```

Open <http://localhost:8000/>. The page does not work from `file://`, because it loads the clips with `fetch`.

There are no automated tests. Verify a change in a browser:

1. Reload and watch the reveal: the figure fills in from bottom to top.
2. Move the pointer around the head. Only the face turns. The body must not follow the pointer.
3. Click left of, right of, above, and below the figure. Check the burst, the swat, and the return to rest.
4. Type a few keys, then press `1` to `6`.
5. Check the console for errors.

Motion matters here. A still screenshot does not show whether a movement looks natural, so say so when you could only check still frames.

## Conventions

- Plain modern JavaScript. No dependencies.
- Settings are named constants near the top of the script. Add a new setting there, with a short comment that gives its unit.
- Positions inside the figure are clip coordinates: 0 to 1 across the square clip, with the origin at the top left. The grid is wider than the clip by `SIDE` on each side. Convert between cells and clip coordinates with `clipCols` and `padCols`, not with `cols`.
- Comments say why, not what. Match the density of the comments that are there.
- The readouts in the corners show real state. Do not add decorative fake values.

## Things that break easily

- **Head turn.** `HEAD.yaw` and `HEAD.pitch` must stay below 0.5, or the warp folds over itself. The `HEAD` ellipse covers the face only. The ears and the earcup must stay outside it.
- **Body motion.** The body must not move toward the pointer. It moves only during a swat, and it returns to rest.
- **Leg at rest.** At the start and the end of a swat, the drawn leg must lie on the leg of the clip. If you move `PAWS` or `ELBOW_Y`, check that the leg does not pop in or out.
- **Leg look.** No dark outline around the leg. A soft shadow separates it from the body. Keep the leg short and thick, like the rest of the figure.
- **Draw order.** The swat is drawn into the clip frame before the head turn and before the glyph step. Keep that order, so the leg gets the same warp and shading as the body.
- **Reduced motion.** With `prefers-reduced-motion`, a click starts no burst and no swat.

## Clip data

To change the clips, change `tools/bake.py` or its input and bake again. The page reads the grid size, frame rate, and colors from `assets/clips.json`, so those can change without a page edit.

The source videos and other source media are not published. `.gitignore` excludes them. Do not commit video or image files.
